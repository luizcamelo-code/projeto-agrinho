# 🌍 EcoProject - Website Sustentável

Um website moderno, responsivo e interativo focado em conscientização ambiental, sustentabilidade e conservação ecológica. O projeto conta com seções informativas, exibição de dados de impacto e ferramentas interativas como um quiz e uma calculadora ecológica.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização moderna utilizando recursos avançados como:
    * **CSS Grid (Auto-fit):** Para layouts de cartões e dados totalmente responsivos.
    * **Flexbox:** Para alinhamento de componentes e barra de navegação.
    * **Efeitos Visuais:** Gradientes lineares (`linear-gradient`) e sobreposições de imagens.
    * **Posicionamento Sticky:** Menu de navegação fixo no topo durante a rolagem.

## 📋 Funcionalidades

* **Design Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops através de Media Queries.
* **Navegação Suave:** Rolagem suave (`scroll-behavior: smooth`) ao clicar nos links do menu.
* **Seção de Impacto:** Exibição de dados e estatísticas em cartões estilizados.
* **Área Interativa:** Componentes prontos para receber lógica de formulários ou scripts (Quiz e Calculadora de Pegada de Carbono).
